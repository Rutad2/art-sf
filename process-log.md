Art SF - Development Process Log

What I worked on

For this project, I created Art SF, a mobile-first website that allows users to explore public artworks in San Francisco. I used the city’s Civic Art Collection dataset and narrowed it from 1,038 records to 100 artworks.

I started by planning the interface in Figma, then worked on the website using HTML, CSS, and JavaScript in Adobe Dreamweaver. Once the website was ready, I uploaded the project to GitHub.

Decisions I made
- Dataset: I chose to use 100 artworks instead of the entire dataset to keep the information more manageable.
- Categories: I grouped different artwork mediums into simpler categories to make filtering easier.
- Images: Since the dataset did not include artwork photos, I used colored blocks based on each artwork’s category.
- Navigation: I used bottom navigation for Explore, Saved, and About to make the main sections easy to access on mobile.
- Design: I used my Figma wireframes as a starting point but made adjustments while developing the actual website.

Challenges and Solutions

My biggest challenge was working with JavaScript because I had never used it before. I was more familiar with HTML and CSS, but I had trouble understanding how to make the website interactive.
I used Claude to help me review my existing code and implement features like searching, filtering, switching between screens, and saving artworks.
Another challenge was working with the dataset. Some artwork records contained inconsistent location information, and the dataset did not provide photos. I kept the original location information and used category-based color blocks as an alternative to images.
